# NetShare Plus (Android 8+)

Экспериментальное Android-приложение для раздачи подключения через Wi‑Fi Direct и HTTP-прокси.

## Сборка APK

В репозитории настроен GitHub Actions workflow `.github/workflows/android.yml`. После добавления исходников откройте вкладку **Actions**, выберите **Build Android APK** и запустите workflow. APK появится в Artifacts после успешной сборки.

## Важно

Это прототип: совместимость зависит от устройства и прошивки. Wi‑Fi Direct не гарантирует маршрутизацию мобильного интернета на всех телефонах. Используйте только в доверенной сети.
